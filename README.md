# KOMPRE QUEST 🃏

Game kartu tempur ala roguelike untuk latihan Ujian Komprehensif S1 Perbankan Syariah.
8 bos = 8 tema materi (Fiqh Muamalah, Ekonomi Islam, Fiqh Ibadah, Akad & Produk, Perbankan,
Laporan Keuangan, Metodologi, Interdisipliner). Jawab PG -> kartu menyerang bos sesuai rank-nya.

Main langsung: https://zeepsha.github.io/kompre-quest/
